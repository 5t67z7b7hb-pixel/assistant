VOICE ASSISTANT — ONE DOWNLOAD

To install and open the assistant, extract this ZIP, then double-click:
  Install Assistant.bat

The installer sets up the assistant, its included Qwen3 model, Python
packages, and Ollama. It opens the assistant when setup finishes. It needs
internet access to download Python/Ollama if missing and install packages.
First setup can take a while. Allow at least 8 GB of free disk space.

After setup, double-click Start Assistant.bat to open it again.
