# Shared UI Components

## Tkinter UI primitives

There is no separate component library or reusable UI package. The assistant screen is composed from native `tkinter` frames, labels, buttons, entries, a question label, a readonly answer text widget, scrollbars, and a canvas equalizer inside `LightningStealthAssistant.setup_ui` in `main.py`. See `layouts.md` for the source location and component inventory.
